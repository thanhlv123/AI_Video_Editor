M110.4 - Unified Media Ranking

Purpose
-------
Compare the current render-safe stock result with preview-only YouTube references on a per-scene basis.

Safety / rights boundary
------------------------
- YouTube remains preview/reference metadata only.
- M110.4 never downloads YouTube audiovisual bytes.
- M110.4 never marks a YouTube reference as render eligible.
- A validated Pexels/Pixabay/local asset remains the render-safe fallback.

Output
------
<project>\work\automation\run_...\media_ranking_manifest.json

Actions
-------
keep_stock
reference_guided_research
broaden_stock_search

M110.5 will consume the ranking actions and perform automatic fallback/re-search for render-safe media.
